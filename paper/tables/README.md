# Canonical result tables

Generated by `python paper/scripts/build_tables.py` from the run logs in `logs/`
(retrieved from Narval). **Every number in the manuscript must be read from one of
these files**; `paper/scripts/check_numbers.py` verifies this before submission.
Units: SeK, Fscd, mIoU and OA in percentage points.

| file | content | primary source |
|---|---|---|
| `second_runs.csv` | per-seed SECOND test results (120 epochs; 200-epoch extension and 200-epoch baseline) | `logs/confirm*/analyse/runs.csv`, `logs/e200_landsat/analyse/kdlogits_e200_runs.csv`, `logs/baseline_augswap_ema/*/metrics.csv` |
| `second_arms.csv` | arm means, Welch gains with 95 % CI, paired gains, student − teacher one-sample tests, gap closed | derived from `second_runs.csv` |
| `second_pairwise.csv` | paired-by-seed contrasts: semantic term increment, ViT-G vs VMamba-B teacher, 200 vs 120 epochs | derived |
| `teachers_reproduction.csv` | re-evaluation of the two published teacher checkpoints (JSON dumps) | `logs/step_0_4026049.json`, `logs/confirm_vmb/checks/step_0_vmambab_4265829.json` |
| `screening_arms.csv`, `screening_runs.csv`, `screening_increments.csv` | KD screening on the SECOND internal validation split (2 671 / 297), 32 runs, 2 seeds per arm | `logs/screen_w4/analyse_all/`, `logs/screen_w3/analyse_all/` |
| `efficiency.csv` | parameters, GMACs, latency, peak memory, same A100 (job 4181178) | `logs/final_tables/efficiency.csv` |
| `training_cost.csv` | per-run training time by setting | `logs/final_tables/training_cost.csv` |
| `compute_cost.csv` | A100-hours per study (sacct for SECOND, timing.csv for Landsat) | journal + `logs/**/timing.csv` |
| `published_second.csv` | published SECOND results used for positioning, with provenance | papers; rows marked measured are ours |
| `landsat_leakage_checks.csv` | pixel-level leakage verification of the LandsatSCD512 random split | `scripts/verify_landsat_leakage.py` (Narval, 1 Oct 2026) |
| `landsat_leakage_pairs.csv`, `landsat_leakage_summary.csv` | per-pair presence of both images in train | `logs/landsat_e600/analyse/landsat_split_leakage.csv` |
| `landsat_random_split.csv`, `landsat_e600_slopes.csv` | student on the leaky random split (250 / 600 epochs), oracle, published PerASCD | `logs/e200_landsat/`, `logs/landsat_e600/` |
| `landsat_loc_base_folds.csv` | location-disjoint folds: student baselines per fold (gate thresholds) | `logs/landsat_loc/analyse/` |
| `landsat_loc_teachers.csv` | per-fold PerASCD ViT-G teachers, gate, teacher − student | `logs/landsat_loc/analyse/` |
| `landsat_loc_kd_runs.csv`, `landsat_loc_kd_folds.csv`, `landsat_loc_kd_stats.csv` | 24 runs (KD and no KD), per-fold summary, primary (folds 1–3) and secondary (folds 0–3) tests | `logs/landsat_loc/analyse/` |
| `gain_vs_teacher_advantage.csv`, `gain_vs_teacher_advantage_corr.csv` | KD gain against teacher advantage over the no-KD student, 6 configurations | derived |

Selection conventions: SECOND has no official validation split, so SECOND numbers are
the maximum test SeK over epochs (field convention, also used by ChangeMamba and
PerASCD) **and** the final-epoch SeK, which involves no selection. Landsat-SCD numbers
are the test SeK at the epoch of best validation SeK of the fold.
